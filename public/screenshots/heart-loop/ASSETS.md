# Heart Loop assets

The editable Android and iPhone decks in `projects/heart-loop.json` use the 11 captures in `screens/`. The file `feature-graphic.png` is the 1024×500 Google Play banner; regenerate it with `node scripts/export-heartloop-feature.mjs` from the repository root.

The screenshot PNGs and exported banner are intentionally ignored by Git in this repository. Keep this folder with the project JSON when moving or publishing the deck. The original PNGs in the repository root were left untouched.

The wide `heartloop-hero.png` is a visual reference for the brand direction and is not a mobile screen capture.
